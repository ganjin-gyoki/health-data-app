プライバシーポリシー

health-data ・ 最終更新 2026年10月9日

利用者

health-data は作者本人1人だけが使う個人用のツールです。作者以外の人のデータは扱いません。

読み取るデータ

作者自身の Google アカウントから、次の読み取り専用の権限で Google Health API のデータを読み取ります。

  • 睡眠（googlehealth.sleep.readonly）：睡眠の時間帯、睡眠時間、睡眠段階
  • 活動（googlehealth.activity_and_fitness.readonly）：歩数、消費カロリー
  • 計測値（googlehealth.health_metrics_and_measurements.readonly）：体重、体脂肪率、安静時心拍

このほか、レポートを作者自身のアドレスへ送るために Gmail の送信権限（gmail.send）を使います。メールの読み取りや削除はしません。

データの使い方

  • 読み取ったデータは、作者本人に向けた毎朝の健康レポートを作るためだけに使います。
  • レポートの文章を作るため、集計した値を Anthropic 社の Claude に渡します。
  • できあがったレポートは、作者自身の Gmail アドレスへ送り、作者の非公開の GitHub リポジトリに保存します。
  • 取得した元のデータと認証情報は、作者のパソコンの中にだけ保存します。

第三者への提供

データを販売したり、広告に使ったり、上に書いた以外の第三者へ渡したりはしません。Google API から受け取ったデータの使い方は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

削除

作者は、Google アカウントの設定からこのツールの権限をいつでも取り消せます。パソコンに保存したデータと認証情報は、ファイルを消せば削除できます。

Privacy Policy (English summary)

health-data is used only by its author. It reads the author's own sleep, activity and body measurement data from the Google Health API with read-only scopes, and uses the gmail.send scope only to email the report to the author's own address. Aggregated values are sent to Anthropic's Claude to write the report text. Reports are emailed to the author and stored in the author's private GitHub repository; raw data and credentials stay on the author's computer. Data is never sold, used for advertising, or shared with any other party. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
